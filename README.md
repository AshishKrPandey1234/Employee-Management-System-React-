# Employee Management System (React)

A frontend-based Employee Management System built using React and Tailwind CSS.  
This application provides role-based access for Admin and Employees with a dashboard to manage and track tasks.

---

## 🚀 Features

- Role-based authentication (Admin & Employee)
- Employee dashboard with task summary
- Task status tracking (New, Active, Completed, Failed)
- Admin dashboard for task overview
- Persistent data using localStorage
- Responsive UI using Tailwind CSS

---

## 🛠 Tech Stack

- React (Vite)
- JavaScript (ES6+)
- Tailwind CSS
- Context API (State Management)
- LocalStorage (Mock Database)
